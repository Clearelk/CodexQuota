位置预设实际移动当前显示器上的悬浮球，大小范围 75%–150%。三个显示开关只影响详情面板。设置保存后生效，旧设置和旧自定义刷新间隔继续保留。开机启动操作真实注册项；恢复默认会重置待保存项并尝试关闭开机启动，失败时保留真实状态。

刷新默认保留 2 分钟。通知默认关闭；开启后，主桶限制时段的新鲜剩余额度低于阈值才提醒，同一次低额度状态不会每次刷新重复提醒。Windows 通知策略可能隐藏实际通知。今日消耗仍是本次运行观测的主额度百分点增量，并非官方整日统计。

点击球展开详情后，点击球/详情/设置/本程序弹出菜单以外的地方会收起详情；拖拽和菜单行为保留。交互不会增加额度请求或本地扫描。
