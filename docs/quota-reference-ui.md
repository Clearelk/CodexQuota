# 参考图界面与简化今日用量

2026-10-12 完成；用户要求由主会话直接实现并自行检查，无代理委派。

## 界面变化

- 详情面板由 420 DIP 缩至 360 DIP，进度条限制在 286 DIP，使用白底、浅冷灰卡片、圆角条和更清晰的字号层次。
- 按参考图将剩余 0–70% 显示为橙黄色，71–100% 为绿色；剩余数字、环形和托盘保持同一策略。连接正常的球/面板状态圆点独立显示绿色。
- 删除可见积分余额、Token 总量和次时段消耗估算。今日用量显示 `12 个对话 / 估算消耗 约18%`，对话数使用本机活跃会话数，估算只选择主额度 `primary`。
- 保留非官方标记、信息提示、等待/暂无估算/部分统计状态。首次观测不制造 0%，缺少主额度不替代为次时段，旧日期数据不会冒充今日。
- 补齐原生矢量齿轮、关闭、信息、时钟、刷新、灯泡图标；状态区展示连接、上次刷新与上次尝试，操作提示移到分隔页脚。
- 保留 72 DIP 悬浮球、悬停/点击固定/拖动跟随、原生定位、设置/托盘和深色主题；不增加扫描、官方请求或依赖。

## 范围与限制

观测消耗只涵盖本次运行、今日、当前账号中可比较的主额度区间，可能包含其他设备使用，重启会丢失此前观测；它不是官方完整日统计，也不是 Token 换算。统计算法、传输和扫描均未改变。

事件验证使用真实 WPF 路由事件、定时器与原生窗口几何，不代表物理鼠标、混合 DPI 热插拔或实际登录验证。当前目录未使用 Git，因此没有产生提交；修改前的文件备份在 `artifacts/verification/quota-reference-ui/baseline/`。
