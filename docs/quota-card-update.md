# 额度卡片与本地今日用量更新

> 此页保留上一版说明。最新拖动跟随、颜色与观测用量更新见[当前说明](panel-follow-observed-usage.md)。

2026-10-12。当前发布文件：`artifacts/win-x64/CodexQuota.Desktop.exe`。请保留完整发布目录。

悬浮球改为圆环样式，显示剩余百分比、Codex 和决定当前最低剩余额度的时段。详情采用圆角卡片，左侧显示主额度/次时段及周期，右侧显示剩余百分比，下方显示剩余进度、已用比例和重置时间。已去掉“充足/偏低/紧张”等文字，并支持浅色、深色和系统主题。

鼠标左键按住球即可自由拖动，松开后保存位置，重启会恢复；程序只会在超出屏幕工作区时将球调整回可见范围。悬停约 0.3 秒展开详情，单击固定，再次单击关闭；拖动不会误触单击，也不会触发额度查询。详情右上角齿轮或右键菜单可打开设置，调整透明度和开机启动。开机启动状态来自真实注册表，默认关闭。

额度仍由官方 Codex 客户端的账号接口读取，复用已有官方登录；悬浮球不另设登录入口，不请求模型回答。正常刷新不再调用可选的官方每日用量接口。

今日卡片显示本机当天有新增用量记录的会话数和 Token，并明确标注“本地统计”和“非官方”。统计包括本机记录的 agent 会话，跨本机已记录账号；不包含其他电脑或网页上未写入本机记录的活动。按事件时间和本机日期归属，用累计 Token 的有效增量避免重复计数。Token 不换算成额度百分比。详细方法在卡片的信息提示中，无法完整归属、记录重复、读取受限等情况会显示“部分统计”；没有可读取来源时显示不可用。

记录扫描在后台进行，只读取 Codex 的 sessions/archived_sessions JSONL，不读取凭据文件，不增加网络请求或子进程。首次按预算读取，之后仅处理新增记录。程序不保存原始记录、账号、Token 统计或凭据；设置文件只保存偏好。

最终验证通过 185 项自动测试、77 项发布版呈现检查和 53 项实际 WPF 事件检查。深浅主题、长数字、未知/过期额度以及拖动保存/恢复已核对。实测正常球单独运行的平均工作集约 131.65 MiB、私有内存约 59.02 MiB；45 秒空闲采样 CPU 增量为 0。刷新时球和官方助手的同时采样工作集峰值为 186.48 MiB。面板开启、日志规模和系统状态会改变占用；这些是本机观察值。

已知边界：多份同一会话的记录取保守值并标记部分统计；文件重写检测使用元数据和局部指纹，不保证识别所有保留元数据的重写。尚未进行物理鼠标注入、真实混合 DPI/热插拔、多显示器硬件或实际 Windows 登录自启测试。
