# 拖动跟随、颜色与观测用量更新

2026-10-12。运行 `artifacts/win-x64/CodexQuota.Desktop.exe`，请保留完整发布目录。

现在拖动悬浮球时，已经打开的详情面板会连续跟随，固定的面板也一样。松手后球若需要回到屏幕可见范围，面板会跟到最终位置；隐藏的面板保持隐藏。位置仍在松手时保存，悬停约 0.3 秒查看、单击固定、再次单击关闭。拖动不会触发额度刷新或本机扫描。

剩余额度颜色按以下区间统一用于圆环、详情剩余数字/进度条和托盘：

| 剩余百分比 | 颜色 |
|---|---|
| 0–30% | 红色 |
| 31–70% | 黄色 |
| 71–100% | 绿色 |

0% 的圆环没有剩余弧，数字显示红色。未知或过期数据使用中性色，不显示“充足”“偏低”等程度词。详情的连接状态圆点另按读取状态显示，正常连接为绿色。

今日用量保留本机会话数和 Token，并增加“今日观测消耗（估算）”，按主额度、次时段分别显示 `约xx%`。它使用本工具今天运行期间已经读到的官方额度变化：例如某时段已用从 10% 变为 15%，观测消耗为该时段完整额度的约 5%。

第一次成功读取只建立起点，第二次可比较读取后才显示数值，期间无变化可以显示约 0%。读取中断、重置等缺口会标注“部分”；重启、跨日、账号切换会重新建立起点，预算变化也不会混入旧预算的统计。同一预算跨多个可确认区间累计可能超过 100%。

这是当前账号的观测估算，可能包含其他设备的使用，也会缺少没有观测到的使用；它不是官方整日统计。Token 仍是本机维度的独立统计，不换算成额度。悬浮球复用官方 Codex 客户端的登录，无需另行登录；额度仍只经官方客户端只读接口获取，沿用原有刷新节奏。

你的位置、主题、透明度、刷新间隔和 CLI 路径会保留。开机启动可在设置中开启或关闭；默认关闭，开关以真实注册表状态为准。
